# Polynomial Regression Assignment (IMT2023592)

Polynomial regression on two personalised datasets:

- **var1** – turbine optimisation, 6 inputs (`x1`–`x6`), polynomial degree up to 10
- **var2** – thermal reservoir mapping, 3 inputs (`x1`–`x3`), polynomial degree up to 20

The target is `y`. Predictions on the test files are evaluated with MSE and R².

## Final models

| Problem | Model | Terms | CV MSE | CV R² |
|---|---|---|---|---|
| var1 | Degree-5 polynomial + Lasso (alpha = 0.01) | 461 (114 kept) | 0.354 | 0.965 |
| var2 | Degree-12 polynomial + Ridge (alpha = 0.1) | 454 | 0.251 | 0.995 |

CV scores are 5-fold cross-validation repeated 3 times on the training data. The test targets are hidden, so the real test error cannot be computed.

## How to run

1. Open `polynomial_regression_clean.ipynb` in Google Colab (or Jupyter).
2. Upload the four CSV files when the first cell asks (in Jupyter, keep them in the same folder as the notebook).
3. Run all cells in order. Section 6 writes the two prediction files, and section 6b downloads them in Colab.

Requirements: Python 3, numpy, pandas, matplotlib, seaborn, scikit-learn.

## Approach in brief

1. **Features.** Every monomial with total degree up to `d` is generated by hand and checked against scikit-learn's `PolynomialFeatures`.
2. **Closed-form Ridge.** The solution `(XᵀX + λI)⁻¹Xᵀy` is implemented by hand and matches scikit-learn's `Ridge`.
3. **Degree selection.** Ridge is fitted for each degree with several penalty values, and the degree with the lowest 5-fold CV MSE is chosen. var1 has a clear minimum at degree 5. var2 reaches a flat plateau from degree 10 to 16, and degree 12 is used.
4. **Lasso for var1.** Lasso on standardised degree-5 terms removes about 75% of the terms and lowers CV MSE from 0.511 (Ridge) to 0.354. It also does better on a test-like split (train on rows with at most 2 clipped inputs, validate on rows with at least 3), because the var1 test set has more inputs at the ±1 boundary than the training set.
5. **Ridge for var2.** Lasso gave no improvement on var2, so Ridge is kept.

## Notes

- All inputs lie in [-1, 1] and many values sit exactly on ±1 (the data appears clipped). In var1, about 32% of training values are on ±1 against about 50% in the test set, so the real test error is probably somewhat above the CV figure.
- The var2 degree is one point on a plateau, not a unique optimum.
